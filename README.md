# Elvis - Data Build Tools (dbt) Project

So named after a recognizeable figure of Las Vegas, this project will explore various free datasets about the Las Vegas Valley. 

# Goals

The goal of this project is to create a portfolio that will aid in getting a Analytics Engineering position in Seattle.
