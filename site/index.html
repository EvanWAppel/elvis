02 / Under the surface

Messy sources.
Clear perspective.

Good stories begin with trustworthy data. Elvis brings scattered public records into one reproducible, testable pipeline.

  1. 01 / Collect

    Find the signal.

    Public records from city agencies, health districts, and environmental sources.

    Open APIs + bulk files
  2. 02 / Load

    Bring it together.

    Python loaders turn separate sources into a single, queryable warehouse.

    Python + DuckDB
  3. 03 / Model & test

    Make it trustworthy.

    SQL models clean and reshape the data. Tests check the modeled records.

    dbt + SQL
  4. 04 / Explore

    Let curiosity lead.

    Maps, filters, and charts make the valley’s public data yours to investigate.

    Streamlit + pydeck
The whole process is open source. Look under the hood ↗
03 / A note on the project

A little less neon.
A lot more nuance.

Las Vegas is more than its postcard. Elvis is an independent analytics-engineering project by Evan Appel, built to make the valley’s public data useful, approachable, and worth exploring.

From public art to restaurant inspections to the changing desert, every view starts with an open source and a question about the place we call a city.
